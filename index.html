7. Grammar Arcade

23 minutes · First & second conditionals · Three games, 45 rounds

Power-up: understand the difference

🟢 First conditional

If + present simple
will + base verb

Real / likely future result.

If I turn off notifications, I will concentrate better.

🟣 Second conditional

If + past simple
would + base verb

Imaginary / hypothetical situation.

If I had a robot, it would do my homework.

Watch out! Don't use will after if in the first conditional. Don't use would after if in the second conditional. “Unless” means “if ... not”.
